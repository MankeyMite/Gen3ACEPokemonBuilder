How to Spawn Pokémon with the custom ACE Pokémon builder website (using a Base64 writer)

The custom ACE Pokémon builder website will allow you to create any Pokémon with any data and spawn it inside your Pokémon game using the Base64 codes provided after clicking the Generate button. This feature is most useful for console users, as there are easier ways to copy Pokémon data on a computer with an emulator, such as copying the Hex data and pasting it into Pokeglitzer.

When generating a Pokémon with the website, you will see 14 box codes. Typing these 14 box codes into your PC and executing it with any stable ace species and the BASE64 writer will spawn that exact Pokémon into your PC, box 14 slot 30. Here is how you create the BASE64 writer:

Creating the BASE64 writer

Make sure of the following before getting started:

  • You have created a stable or metastable ace species using the Dots egg. (Stable ARM species 0x410e recommended for English, French, German, Italian, and Spanish versions.)
  • Boxes 11–14 are empty.
  • Box 10 slot 22 is empty.

Select Console/mGBA, Old Emulator, or MyBoy Emulator below. Any Nintendo console with a real cartridge or mGBA emulator version 0.9 or newer is considered "Console", and most other emulators are considered "Old Emulator".

You may now start typing the first code. Then execute it and keep going with the next codes until your setup is complete.

Japanese Emerald BASE64 writer setup

This guide currently supports Japanese Emerald only.

You need a stable THUMB ACE species, such as 0x085F. This is the standard stable ACE species obtained after the DOTS setup on Japanese versions.

Open the Setup code tab and enter the Japanese box names exactly as shown. Highlighted blank cells are spaces and must be included where shown.

You may now start typing the first code. Then execute it and do the DexReg code to make built Pokémon register in the Pokédex.
