How to Spawn Pokémon with the custom ACE Pokémon builder tool (using a Base64 writer)

The custom ACE Pokémon builder tool will allow you to create any Pokémon with any data and spawn it inside your Pokémon game using the Base64 codes provided after clicking the Generate button. This feature is most useful for console users, as there are easier ways to copy Pokémon data on a computer with an emulator, such as copying the Hex data and pasting it into Pokeglitzer.

When generating a Pokémon with the tool, you will see 14 box codes. Typing these 14 box codes into your PC and executing it with any stable ace species and the BASE64 writer will spawn that exact Pokémon into your PC, box 14 slot 30. Here is how you create the BASE64 writer:

Creating the BASE64 writer

Make sure of the following before getting started:

  • You have created a stable or metastable ace species using the Dots egg. (Stable ARM species 0x410e recommended on western language versions. Japanese versions not yet supported for this guide!).
  • Boxes 11–14 are empty.
  • Box 10 slot 22 is empty.

You may now select Console/mGBA, Old Emulator, or MyBoy Emulator below and start typing the first code. Any Nintendo console with a real cartridge or mGBA emulator version 0.9 or newer is considered "Console", and most other emulators are considered "Old Emulator".
