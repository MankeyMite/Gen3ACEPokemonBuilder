Gen 3 ACE Pokémon Builder

v.0.5.1

Generate any Pokémon and make them spawn in your in-game PC, using a stable ACE species with a Base64 writer! No external tools needed. This tool is unfinished, and bugs are expected. Any feedback is appreciated! Contact me on Discord: MankeyMite#9981

How it works

  1. Set up the Base64 writer first. Click here
  2. Build any Pokémon you want by filling out the fields below.
  3. Click Generate and type the code into your PC box names.
  4. Execute the code with your stable ACE species. The Pokémon will appear in Box 14, Slot 30!

Tip: Pokémon made with this tool is designed to be legal for transfer through Pokémon Bank/Home. Turning Legal Mode off allows more customization, but can create illegal combinations.

Stats

Base IV IVs range from 0 to 31 in each stat, and each point equals 1 stat point at level 100. IVs are controlled by the selected legal encounter. In hatched mode, any combination is automatically legal. EV EVs add extra stat points, scaling to 1 stat point per 4 EVs at level 100. You can use up to 510 EVs total. 252 is the highest useful value per stat, because the stored maximum is 255 and reaching the next stat point would require 256 EVs. This tool therefore caps each stat at 252. Total
